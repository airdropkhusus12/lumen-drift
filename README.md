# Lumen Drift

A neon arcade game for make.fun best-game-01.

Pilot a ship through a neon field: collect lumen orbs, dodge asteroids, chain combos, and survive as the speed rises. Three lives, escalating levels, score and best-score tracking, start screen, HUD, game over and restart — all in static files, no network.

- `game/` — the playable game (open `game/index.html` in desktop Chrome)
- `main.ts` — the submission program (copies `game/` + `screenshots/` and writes `dossier.json`)
- `serve.ts` — tiny static server (`node serve.ts`, then http://localhost:8080)
- `screenshots/` — 3 screenshots of the running game
